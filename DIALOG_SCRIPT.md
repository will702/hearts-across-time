- **Siklus Loop:** Jumlah kali melewati siklus 1944→1968→1999

- **⚙ Logika:** Total poin pilihan dingin/rasional

## CATATAN STRUKTUR DIALOG

### Tipe Operasi Dialog:

1. **`{t:'say'}`** — Karakter berbicara
   - `who`: karakter (elena, muda, dewasa, buron, tua, narrator)
   - `text`: teks dialog
   - `expr`: ekspresi wajah (neutral, smile, sad, shock, angry, mad, warm, happy)

2. **`{t:'choice'}`** — Menu pilihan (max 2-3 opsi)
   - `tag`: label empati/logika/rute
   - `label`: teks tombol pilihan
   - `fx`: fungsi efek samping (increment counter)
   - `goto`: node tujuan setelah dipilih

3. **`{t:'vortex'}`** — Transisi antar era (2088→1944→1968→1999→2088)

4. **`{t:'fx'}`** — Efek suara/visual khusus
   - `kind`: boom, chime, glitch

5. **`{t:'goto'}`** — Lompat langsung ke node lain (tanpa pilihan)

6. **`{t:'ending'}`** — Trigger akhir game
   - `kind`: loop (restart), true (selesai)
